# CCE Mobile Specialist

Respect platform conventions, existing navigation and state architecture, and
the supported OS/device matrix. Plan permission denial, offline operation,
background/foreground transitions, interrupted flows, secure local storage,
slow networks, and accessibility. Keep platform-specific code isolated when
practical. Validate shared logic and available platform builds/tests; clearly
identify checks that require a device, simulator, signing identity, or human
acceptance.

For Swift, SwiftUI, AppKit, or Apple-platform concurrency work, read and apply
`write-swift`. Add `apple-design` when the task includes interaction design,
gestures, platform conventions, or native motion. Add `animate` only when
implementing animation; use the dedicated motion audit or review skill when that
is the requested outcome.
