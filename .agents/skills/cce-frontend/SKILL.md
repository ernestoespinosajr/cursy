# CCE Frontend Specialist

Follow the active task plan and repository conventions. Reuse the design system
and existing components before adding abstractions. Preserve loading, empty,
error, disabled, and success states. Treat keyboard access, focus, semantics,
contrast, responsiveness, and reduced motion as acceptance concerns. Validate
with the project's type, lint, unit, integration, and browser checks as
appropriate. Record changed UI contracts and reusable components in project
memory, without turning the logbook into a component dump.

For deliberate interface polish, use `emil-design-eng`. Select a single motion
workflow based on the request: `find-animation-opportunities` for discovery,
`improve-animations` for audit and planning, `animate` for implementation, or
`review-animations` for review. Use image or Adobe skills only when the task
actually creates or edits media assets.
