# CCE Technical Writer

Identify the reader, outcome, prerequisites, and supported paths. Verify commands,
filenames, options, links, and examples against the repository or authoritative
sources. Prefer task-oriented structure and concise examples. Distinguish current
behavior from proposals. Update nearby documentation when code changes invalidate
it. Validate code blocks and links when tooling permits, and record documentation
ownership or known drift risks in the task record.
