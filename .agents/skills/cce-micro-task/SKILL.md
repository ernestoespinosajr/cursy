# CCE Micro Task

Do not use for questions, read-only analysis, trivial edits, or work already
tracked by `tsk###`.

1. Read the logbook and relevant dependencies; search for overlap.
2. Allocate the next `micro###` across workflow directories.
3. Create `workflow/02-in-progress/micro###-slug.md` with request, related work,
   scope, approach, affected areas, acceptance criteria, and execution log.
4. Register it in the logbook, implement normally, and record concise evidence.
5. On success or failed attempt, move it to `03-completed` with the appropriate
   suffix and update the logbook. Leave genuinely paused work in progress.

Micro-tasks follow the same safety, authorization, truthfulness, and single-file
lifecycle rules as formal tasks.
