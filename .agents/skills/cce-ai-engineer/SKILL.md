# CCE AI Engineer

Use current official documentation for model and API behavior. Keep provider
calls behind clear interfaces, validate structured output, and design retry,
timeout, rate-limit, fallback, and data-handling behavior. Define an evaluation
set and measurable quality threshold before optimizing prompts. Test deterministic
surrounding logic separately from model behavior. Track model/version assumptions,
latency and cost considerations, safety boundaries, and known evaluation gaps;
never place API keys or sensitive prompts/data in workflow records.
